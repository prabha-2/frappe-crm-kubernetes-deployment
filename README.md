# Kubernetes Learning & Frappe CRM Deployment on AWS EKS

This repository documents my hands-on learning and practical experience with Kubernetes, followed by deploying Frappe CRM on Amazon Elastic Kubernetes Service (EKS).

## Repository Overview

### Part 1: Kubernetes Fundamentals

A collection of documentation covering core Kubernetes concepts:

- Kubernetes architecture
- Pods, Deployments and workloads
- Services and networking
- Persistent storage
- ConfigMaps and Secrets
- Troubleshooting

[Explore Kubernetes Basics](./01-kubernetes-basics/README.md)

### Part 2: Frappe CRM Deployment on AWS EKS

A hands-on project where I practised deploying Frappe CRM using Kubernetes on AWS EKS.

**Technologies used:**
- AWS EKS
- Kubernetes
- Docker
- Amazon EBS
- MariaDB
- Redis
- Frappe Framework
- Bash

**What I practised:**
- Setting up an EKS cluster
- Deploying application and database workloads
- Configuring Kubernetes Services
- Managing application configuration using ConfigMaps and Secrets
- Configuring persistent storage
- Troubleshooting pod startup and connectivity issues
- Accessing the application through a LoadBalancer Service

[Explore Frappe CRM Deployment](./02-frappe-crm-deployment/README.md)

## Learning Outcomes

Through this work, I gained practical exposure to Kubernetes resource management, application deployment, container orchestration, persistent storage, networking and troubleshooting on AWS EKS.
